About this release

Cliploom now has a browser editor and a separate local Windows edition under the MIT licence. Online automatic transcription, customer accounts, payment plans and ads are not active. Browser video export depends on device support and runs in real time.

QUESTIONS PEOPLE ASK

Good to know.

Can I use it online on my phone?

Yes. Open the online editor in your mobile browser. You can add it to your home screen where your browser supports installation.

Does it support Tanglish?

Yes. Write or import Tamil, Tanglish and English captions. Automatic transcription is currently in the local Windows edition.

Do I need an API key?

No API key is needed for the online editor. The separate Windows edition can run local transcription and optional Ollama suggestions.

Where is the source code?

The GitHub repository contains the MIT-licensed application source.
