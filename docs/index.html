About this release

Cliploom is a free Windows app offered under the MIT licence. This website explains and links to the downloadable app. Online video processing, customer accounts, payment plans and ads are planned features and are not active. The first use requires model downloads and processing speed depends on your computer.

QUESTIONS PEOPLE ASK

Good to know.

Is this an online subtitle editor?

This release is a local Windows app. Download it, start the local server and use the editor in your browser on that computer.

Does it support Tanglish?

Choose Tamil + English for mixed speech. Automatic transcription can mishear mixed language, so check the captions.

Do I need an API key?

No paid API key is needed for local transcription. Optional Ollama clip suggestions require a local Ollama model.

Where is the source code?

The GitHub repository contains the MIT-licensed application source.
